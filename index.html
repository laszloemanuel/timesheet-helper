Első használat: Google OAuth beállítása (egyszeri, ~5 perc)
  1. Menj a console.cloud.google.com oldalra, hozz létre (vagy válassz) egy projektet.
  2. APIs & Services → Library: kapcsold be a Google Calendar API-t.
  3. APIs & Services → OAuth consent screen: External, töltsd ki a kötelező mezőket, add hozzá magad Test user-ként.
  4. Credentials → Create credentials → OAuth client ID → Web application. Az Authorized JavaScript origins-hoz add hozzá ezt az oldalt (pl. a saját URL-ed).
  5. Másold ki a Client ID-t, és illeszd be a ⚙︎ Beállítások alá. Ez nem titok, de itt a böngésződben tárolódik — a repo-ba semmi nem kerül.

A naptáradból letöltött adatok kizárólag a böngésződben maradnak (memória + localStorage). Semmi nem töltődik fel sehova.
